# Orchestra

Music notation, a DAW and a simple video editor in a single program: the score and the
arrangement are two views of the same project, and video is just another kind of track on the
same timeline.

Written in Rust. Linux first; Windows and macOS will follow.

**Status:** foundations complete (phase 0); core time and document model next. Nothing usable yet.
